# 合成参考证据集 v1

日期：2026-11-03。数据位于evaluation/dataset-v1；原应用源码冻结基线7b7f649，本阶段没有修改backend/src/lume中的检索、模型、预算、资格或发布逻辑。

这是助手编制的合成资料与参考标签草稿，不是实际企业数据、人工标注基准或秘密盲测。人工复核数量为0，所有参考状态pending。当前交付用于审阅标签与准备复现实验，不提供模型质量分数。

消息中的“合成验证单”“通过”等字样属于构造的上游事件情节，不是本项目真实执行了缓存、上传、登录、台账等业务实验。不得把这些情节当作系统性能、生产故障或实际业务验收记录写进论文。

## 构成与划分

| 划分 | 情景 | 消息 | 图片 | 问题 | 事实/上下文/视觉/不可回答 |
| --- | ---: | ---: | ---: | ---: | --- |
| 开发 dev | 4 | 24 | 4 | 16 | 各4题 |
| 保留 heldout | 8 | 48 | 8 | 32 | 各8题 |
| 合计 | 12 | 72 | 12 | 48 | 各12题 |

开发情景为缓存代次、分片上传、重试退避、配置发布；保留情景为日报时区、回调白名单、索引别名、合并表格、通知分路、合成台账批次、附件生命周期、长连接心跳。每个情景包含起始事件、未验证建议、修订、验证结论、附件说明和旧环境干扰消息，显式回复链保持在同一情景。

按情景整组划分，同一事件及其改写不跨划分。每题范围包含该划分的多个情景，开发常规查询有24条候选语料，保留常规查询有48条；两题范围排除了目标情景，分别只请求开发其他3组、保留其他7组。开发与保留候选规模不同，跨划分数值不能仅归因于泛化；每次配置比较需在同一划分、语料和范围上进行。

旧联调的三个问题及其错误码、版本和参数没有进入本包。全部保留标签公开存在，作者已接触全量数据；“保留”仅表示未送入目标模型运行或调参的预留问题，不表示对作者保密。若后续查看保留结果并改代码/提示，需登记接触，再使用新数据评价下一版。

## 文件与输入边界

| 文件 | 用途 | 是否可送入模型 |
| --- | --- | --- |
| scenarios.json | 合成消息、回复关系和附件映射 | 只将messages转换为现有MessageInput并接入 |
| assets/*.png | 12张960×520合成原图 | 仅按当前任务资格和inspect_image路径读取 |
| queries-dev.jsonl / queries-heldout.jsonl | 不含题型语义的ID、问题、范围、核图要求 | 只通过task_payload输出实际请求字段 |
| references.jsonl | 离线题型、所属情景、可回答标签、支持摘录、最小证据、视觉真值 | 否 |
| qrels.tsv | 72条拟定消息正例，供后续检索指标使用 | 否 |
| source.json | 助手编制源、问题草稿和绘图参数 | 否 |
| review.md | 48题可读审阅册、完整消息和图像 | 否 |
| manifest.json | 19个数据文件的摘要、数量与生成环境 | 仅用于实验核验，不加入提示 |

查询文件没有category、answerable、expected_state、参考答案或金标准来源。ID为q-dev-001等，不能以unanswerable后缀暗示答案是否存在。`task_payload(query, space_ids)`只输出question、space_ids、require_image，连离线问题ID也不进入Agent请求。类型信息与答案标签只由离线评分/审阅端读取。

不可回答题共12道，其中10道缺少所问记录，2道为scope_exclusion。后者的目标事实在离线包中存在，但不在本次请求范围，正确行为是说明资料不足，不得越界读取。参考中的forbidden_evidence_ids仅用于离线检查，不能提供给模型作提示。

视觉题核对目标卡片圆点的颜色和卡片内左右位置，不能仅用OCR识别字母作答。每题给出原图身份、目标标签、卡片与圆点区域、像素中心、作者指定颜色和左右真值；同图另有干扰卡片。12图使用同一面板模板，目标都在左侧卡片，位置问题指的是卡片内部圆点；这一固定布局是明显限制，不能据此证明复杂界面、真实截图或任意空间关系的理解。

## 参考标签的解释

每道可回答题登记一组拟定最小证据：事实题为已验证消息，上下文题需要4条过程消息，视觉题为原图。集合内部为AND；结构允许多组OR，但当前每题只编制一组，未穷尽所有等价依据。检查器拒绝把上下文的4个单消息误当4组替代集合。未标正的其余消息是未穷尽判断，不因未列入就自动成为确定负例。

检索qrels以稳定source_id为单位；图像证据映射到携图消息m4。因此命中图像题的qrel只证明定位到相应消息，不能证明调用过视觉模型、读对颜色或引用正确。原图检查、答案事实和逐断言引用支持应另行记录。

claims字段当前是待拆分/复核的参考事实块，不是经独立验证的原子断言。消息excerpt用于精确定位，检查其存在不等于已证明整段参考事实受其支持。不能直接用字段条数计算“语义支持率”。中文自由答案不按逐字一致机械判错，同义说法、数值单位、否定范围和环境限定均需按复核规则处理。

不可回答题没有非空相关集合，检索Recall/MRR/nDCG记N/A并另报题数；可回答题分母36，保留可回答题24。失败、超限和错误拒答保留在相应端到端统计中，不只统计成功答案。无输出或空引用不得获得完美支持分数。方法依据及公式见[evaluation-protocol-research.md](evaluation-protocol-research.md)。

## 构建与检查

使用现有Pillow、Pydantic与项目ImageStore，无新增依赖，不启动数据库或模型。

```bash
uv run --frozen python scripts/evaluation_dataset.py build \
  --source evaluation/dataset-v1/source.json --output evaluation/dataset-v1
uv run --frozen python scripts/evaluation_dataset.py check \
  --dataset evaluation/dataset-v1 --report ../outputs/lume-evaluation/dataset-check.json
uv run --frozen pytest -q backend/tests/test_evaluation_dataset.py
```

修改资料先改source.json，再构建和复核。构建会覆盖包内review.md，它是生成的阅读视图；请把人工意见填写在单独维护的docs/evaluation-human-review.md，避免重建覆盖。当前构建器只接受pending/0的人审草稿，不能自动把标签升为已复核；人审完成后应附真实复核记录、修订理由并建立新的冻结版本。

检查覆盖文件摘要、唯一身份、来源摘录、回复和附件归属、图片区域与像素、分组隔离、范围合法性、最小集合逻辑、查询标签隔离、旧样例排除，以及72条MessageInput/ImageStore本地接入。它不判断所有自然语言蕴含、等价证据或缺失事实，不能代替人工标注。

两份干净目录构建在当前锁定环境内摘要一致；不保证不同Pillow、字体或PNG编码库版本跨机器逐字节相同。复现评价时优先使用已冻结PNG并核对manifest，重新生成应披露环境和新摘要。
