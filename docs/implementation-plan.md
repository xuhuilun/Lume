# 首版实施计划

1. 建立可安装后端、配置与持久模型，初始化隔离PostgreSQL/pgvector；验证数据库真实可用。
2. 实现令牌身份、显式空间资格、版本接入、受控图片和后台派生；验证重复、更新和权限边界。
3. 实现词项/向量/RRF、观察、受控模型/工具循环、取消和条件提交；验证引用、依赖、预算及旧执行者。
4. 实现QQ官方签名Webhook与格式回放，核对官方挑战向量和拒绝/去重/群白名单，不调用真实QQ发送接口。
5. 建立React查证工作台，连接实际API与任务轮询，提供合成资料导入与证据查看。
6. 执行后端测试、真实数据库集成、前端类型及构建检查，记录条件与失败；完善README、部署和验证文档，自检后将feature分支合并main并推送指定远端。

首版交付可运行核心，未获凭据的QQ线上回调、真实Ollama模型质量及压力测试不标为通过。论文后续按实际源码和测试回查，保留与原设计的差异。
