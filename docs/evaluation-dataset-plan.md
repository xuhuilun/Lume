# 参考证据集实施计划

日期：2026-11-03。基线为7b7f649，接续真实模型联调后的第二阶段。不生成PDF，不改变当前检索、模型或发布规则。

## 设计

建立evaluation/dataset-v1，包含12个人工构造情景、72条消息、12张程序绘制的合成面板和48个问题。每个情景6条消息：起始事件、未验证建议、修订依据、验证结论、图片说明、旧环境干扰。每个情景4类问题：事实、上下文链、视觉细节、不可回答。图片问题核对颜色及位置，避免把纯OCR文字题冒充全部视觉能力。

4个情景用于开发（16题），另外8个完整情景作为保留划分（32题）。按情景族隔离；同一情景的消息、附件、全部问题及旧环境干扰均归同一划分，不做逐问题随机切分。查询范围包含本划分多个情景，保留相似技术词、待验证建议和旧环境作为干扰。上一阶段E_CONN_42、v1.8、pool_size=20及原三问不进入此包。

这是由助手编制的合成资料与参考标签，不是企业聊天、受访者数据或独立人工标注。标签审阅状态全部pending，人工复核数量0；保留划分不是秘密盲测，作者能够读取全部标签。正式论文质量结论需要复核标签、冻结数据/代码/配置，再执行未用于调参的保留问题。

## 数据与接口

- scenarios.json：只保存接入所需消息、附件路径、情景身份及划分；不包含参考答案。
- queries-dev.jsonl / queries-heldout.jsonl：只有不含题型含义的问题ID、问题、允许情景范围与require_image；类别、所属情景和拒答标签均移到离线references。任务转换接口只输出question、space_ids、require_image，不传问题ID或其他离线信息。
- references.jsonl：离线参考事实、精确消息摘录、最小证据集合、视觉区域与真值、不可回答理由；禁止拼入模型输入。
- source.json：可追溯的助手编制源说明，生成语料/问题/标签；属于离线作者材料，不能作为模型接入内容。
- manifest.json：每个数据文件的SHA256、数量、划分、基线源码及复核状态。生成后验证，改变标签或图像必须改变摘要并保留变更说明。
- docs/evaluation-reference-review.md：可逐题核对的Markdown审阅册，链接原消息和图片，记录待人工复核。

离线脚本负责构建、确定性输出顺序、完整性检查、接入格式校验和审阅册导出，沿用Pillow和Pydantic，不引入第三方依赖。不得运行真实模型或自动生成“准确率”。本阶段检查不等于模型实验。

## 标签和评价约束

证据身份按稳定source_id及image asset key区分。最小证据集合内部为AND，多个集合之间为OR；消息的检索命中与实际读取原图分别登记。图片题的消息qrel映射到携图消息，仅表示定位，不能代替原图观察。引用正确性、逐断言支持性和完整证据覆盖分别核对。

不可回答题不进入以非空相关集定义的Recall/MRR平均；单独评价不足状态与无依据断言。空答案、失败或超限不得被记成完美引用分数；正式计算需同时报告分母和失败。部分题的目标资料位于本次范围之外，参考注明scope_exclusion，允许范围内的正确结果是说明资料不足。

显式核图任务require_image=true用于检查用户要求的原图证据；后续若做“是否提供核图工具”的质量消融，两组必须采用相同请求条件，不能把true的完整系统与false的对照混算。追加查证比较也不能同时改变检索资料、模型或预算而只归因于某一模块。

## 实施与验收

1. 在feature/evaluation-reference-dataset分支编制资料源、问题与逐条支持关系；同步调研评价依据。
2. 构建数据、图片和审阅册，检查唯一身份、引用范围、全部摘录、图片尺寸/区域、无越界路径、划分族隔离、查询无标签以及旧样例排除。
3. 增加能拒绝交叉划分、证据越权、摘录不符、错误图片真值、消息格式无效、资产篡改和标签泄露的回归。
4. 复建两份数据，核对所有数据文件摘要相同；全部消息通过现有MessageInput与ImageStore的本地接入校验，不访问原数据库、不调用模型。
5. 执行相关静态及程序回归；记录结构检查、视觉抽查和人工复核缺口。文档与数据同步后提交，合并main并推送，导出outputs中的Markdown和数据包。

本阶段交付可审阅的评价材料及检查工具；独立标注、目标模型质量分数、QQ线上数据和生产性能仍不在已有证据中。

编制中进一步收紧问标隔离：诸如category=unanswerable及带此后缀的问题ID本身会暴露答案是否存在，因此它们不进入查询文件。改用q-dev-001/q-heldout-001等不含题型的身份，分层统计信息只保留在离线参考记录。新增任务输入白名单转换及相应回归，再冻结本版草稿。
